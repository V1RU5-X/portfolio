Personal portfolio

The site you're on. Built by hand in plain HTML, CSS and JavaScript. It works without JavaScript and can be used entirely from the keyboard.

  • HTML
  • CSS

Repo of Personal portfolio

Case study
Problem
I needed a place to show hiring managers my work, and I wanted the site itself to show I understand the fundamentals, not just a framework.
What I did
I wrote it in plain HTML, CSS and JavaScript with no build step. All the content shows even with JavaScript turned off, and the animations are only added when scripts run. I built accessibility in from the start: a skip link, full keyboard use, the current section announced to screen readers, and a reduced-motion mode that turns off every animation. One bug I'm glad I caught: the text-scramble effect on the nav made links briefly unclickable, so I reworked it so links stay usable while they animate.
Result
A fast site, hosted free on GitHub Pages, that works with JavaScript off, with only a keyboard, and with reduced motion.
